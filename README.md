# teaching-site

Public site for teaching.ericmichaelschwartz.com (GitHub Pages).

Contains only the landing page and **released** interactive tools. Do not edit
`tools/*.html` here — they are copied in from the private `interactives` repo by
its `release.sh`. To release or update a tool, run `release.sh` there, update the
tool's card in `index.html` if needed, then commit and push this repo.
